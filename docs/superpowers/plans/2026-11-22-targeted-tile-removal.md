# Targeted tile removal implementation plan

Run a validation-only experiment on frozen `EAN5-L2-Lin-Mean-Reg-s1` and `CM5-L2-Lin-Attn-Reg-s2` checkpoints. Find the fewest embedding rows that must be deleted to reach the target class on each slide. Compare scattered deletions with compact regions and matched controls, then show the selected regions to a pathologist on the intact slide in xOpat. The first milestone ends with blinded review and a **Targeted tile removal** section in each model's existing tile-explanation HTML report (`report.html`). Index-band search is a follow-up milestone, and selector training depends on the review findings.

This extends the repository's patch-flipping workflow with a target and a minimum deletion count. Start from the checkpoint, data, and viewer helpers at `2c4bcf65bd6e822013a77fb8b1a591457dceef91` (`origin/feat/explainability`). Its `faithfulness.py` shows how to reuse pooling statistics across deletion steps. The experiment always retains at least one original tile. [Fong and Vedaldi's deletion-mask paper](https://arxiv.org/abs/1704.03296)

## 2. Implement the minimum class mask

- [ ] Add `ml/explainability/tile_removal.py` with `minimum_class_mask(scores, log_weights, tile_ids, target_class, *, threshold=0.0, max_removed=None)`. Return removed row IDs, deletion count, predicted index, and search status. The model adapter computes `s_i = vᵀz_i + b` with the frozen head. For mean, `z_i` is the encoded tile and `log_weight_i = 0`. For attention, `z_i` is the aggregator's per-tile LayerNorm output and `log_weight_i` is its pre-softmax gated score. Cache the tile scores and attention logits once per slide. [Mean pooling](../../../ml/models/aggregators/mean.py) · [Gated attention](../../../ml/models/aggregators/attention.py) · [Linear head](../../../ml/models/heads/linear.py)
- [ ] Let `w_i` be the positive weight corresponding to `log_weight_i`. The retained-bag index is `sum(w_i s_i) / sum(w_i)` over retained tiles, so crossing `t` depends on the sign of the retained sum of `c_i = w_i(s_i − t)`. At a fixed deletion count, removing the smallest `c_i` maximizes that sum and removing the largest minimizes it. Sort ascending for A and descending for B, breaking ties by tile ID. The first feasible prefix is a minimum-cardinality mask. Accept `sum >= 0` for A and `sum < 0` for B. Compute in float64 with stable logit scaling and suffix sums. Handle extreme logits with signed log-magnitude ordering and retained-set rescaling when needed.
- [ ] Search counts `0..N−1` to distinguish an impossible flip from a minimum above the reporting budget. Use `min(floor(N × fraction), N−1)` at the proposed 1%, 5%, and 10% budgets. A budget can permit zero deletions. Slice the original bag with the boolean keep mask and rerun the full frozen model for every exported candidate. Check the preceding prefix when a class result claims minimality. If roundoff can change feasibility at the boundary, retain any verified outcome and flag minimum cardinality as unresolved until the boundary is resolved. Persist the native forward index in the report.

**Acceptance.** Add `tests/test_tile_removal.py`. Enumerate every nonempty retained subset of small mean and attention bags and compare the solver's minimum count with the oracle in both directions. Cover LayerNorm, head bias, asymmetric attention weights, ties, threshold equality, high logit spread, all scores on the same side, one tile, and a flip above 10%. Verify repeated runs return the same row IDs.

## 3. Add compact masks and matched controls

- [ ] Add `ml/explainability/tile_removal_regions.py`. Propose a compact search using one axis-aligned square on the original L2 tile grid. Scan squares of side 2, 4, 8, 16, and 32 grid cells anchored at grid positions across the tissue bounding box. Remove tiles whose centers lie in the square, intersected with the source bag. Use rolling or integral counts and contribution sums where memory allows. Select the smallest successful candidate by deleted tile count, then by footprint area and stable location. Cap the compact search at 10% for the pilot. If no candidate reaches the target, save the verified candidate closest to crossing the boundary and its shortfall. Report compact success and minimality within the declared window search, and log any clipped or sparse footprints.
- [ ] For each exported mask family, draw seeded same-slide controls matched on tile count and union footprint area, and on tissue/tumor coverage when the relevant mask exists. Sample scattered controls for scattered masks and windows of comparable scale for compact masks. Freeze matching tolerances and the proposed 20 control draws per mask before scoring the cohort. Make matching independent of model score and attention. Report failed matches rather than widening tolerances silently. Also try one alternative scattered mask with the primary mask's rows forced to stay, using the same budget, to test whether a distinct successful region can support the same outcome.
- [ ] Rerun the frozen model on each exported mask and control. Report tile count, union area, retained tumor area within the original tile-covered footprint, and retained mass of the **original** attention distribution for the attention checkpoint. Use the union of tile footprints for area because L2 tiles can overlap. Treat missing tumor masks as unavailable and record control matches and search parameters. [L2 level configuration](../../../configs/data/levels/l2.yaml)

**Acceptance.** A synthetic grid with a known successful square yields the expected tile IDs, even with holes and overlapping tiles. A fixture with no compact success still returns the best observed candidate. Control selection is reproducible and independent of the forward scores.

## 6. Follow up with an index tolerance band

- [ ] Add index mode using the recorded index `r` and proposed default `ε = 0.05`, yielding the inclusive band `[L, U] = [r−ε, r+ε]`. Keep the same frozen bags and proposed 10% deletion cap. A prediction already in-band yields a zero-deletion mask.
- [ ] Use binary keep variables `k_i`. Minimize `N − sum(k_i)` subject to `sum(k_i) >= N − max_removed`, `sum(k_i) >= 1`, `sum(k_i w_i(s_i−L)) >= 0`, and `sum(k_i w_i(s_i−U)) <= 0`. A class prefix can warm-start or bound the search where useful. Require a solver certificate before claiming minimum count or infeasibility, and verify any candidate through the frozen forward path. If infeasible within budget, search for the smallest symmetric band expansion that has a feasible mask, with a stated error tolerance. If the solver times out, report the best verified candidate and distance to the original band, with bounds where available.

**Acceptance.** Compare against exhaustive subsets on small bags. Include an overshoot case where the class prefix jumps across the entire band, feasible endpoints, an already-in-band case, and an unreachable or time-limited case. Label results as certified minimum, feasible with unresolved minimum, infeasible within budget, or unresolved.
