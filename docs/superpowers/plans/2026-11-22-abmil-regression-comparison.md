# ABMIL regression comparison implementation plan

Test whether a compact per-tile projector improves MammaPrint index regression over slide-mean linear models. Compare mean and gated-attention pooling on frozen L2 Virchow2 embeddings. Use validation to choose the configuration, then evaluate one locked model on the held-out test split. Run an L1 follow-up only after the [resolution comparison](2026-11-22-l1-resolution-comparison.md) supports it. Keep new embeddings, transformers, and spatial encoding outside this work.

## 1. Freeze the cohort and reference models

- [ ] Pin the L2 card, source artifact versions, label mapping, eligible slide IDs, tile counts, exclusions, split assignment, and patient or case grouping. Use `configs/data/embedded/cancer_mask_5/l2.yaml` as the working default so the later L1 comparison can reuse the mask family. If option 3 pins another L2 card, use its card for all arms when it can be reproduced. Reuse the labeled, nonempty slide eligibility in `ml/data/datasets/single_scale.py`. Reject duplicate slide IDs, nonfinite targets, and cross-split overlap. Check patient or case overlap when a verified grouping key is available and record whether grouping could be verified. Resolve discrepancies before interpreting a held-out result.
- [ ] Locate the option 3 ridge fit, including its feature definition, scaling, alpha selection, folds, and validation predictions. Reuse it as the primary reference when its split, slide IDs, labels, and embedding source match. Otherwise, fit a matched ridge on one full-bag raw embedding mean per slide. Cache these vectors keyed by the frozen manifest. Fit any standardization inside the training pipeline and tune alpha using training-only CV on `10^-4` through `10^4` in decade steps, by MAE. Use five patient-grouped folds where group IDs and counts permit. If grouping is unavailable, document the limitation and use fixed slide folds. Refit on the development training partition and score validation once. Keep the historical ridge result as context if its inputs differ.
- [ ] Reuse the established CV protocol if its fold assignments can be recovered and verified against the pinned cohort. Pair methods by fold and seed. Keep checkpoint and alpha selection inside each outer training fold, using a fixed inner validation split for the neural checkpoints. Compute metrics from pooled out-of-fold predictions per seed. With the fixed split fallback, use the existing train/validation artifacts and call the spread seed variability on one split. Reserve the existing test partition in either case.

**Acceptance.** A versioned manifest gives every model the same eligible rows and labels within each partition. It names the reference fit or its matched replacement and records the split protocol. Confirm from membership metadata that test is held out before any scoring job is enabled.

## 2. Add the projector and fixed recipe

- [ ] Add `TileProjector(in_dim, out_dim, dropout)` in `ml/models/encoders/tile_projector.py` and register it with the existing encoder package and Hydra group. Apply `Linear(2560, 256) → GELU → Dropout(0.20)` to each tile. Route the projected dimension to the aggregator and `LinearHead`, preserving 2,560 as the input width. Reuse `MeanPool` and `AttentionMIL`, with a 128-wide gating layer for ABMIL-attention. Add an opt-in identity normalization path to the attention aggregator for the new preset so both pooling arms pool the same projected values. Preserve the existing attention preset's LayerNorm default.
- [ ] Add opt-in scalar head initialization to `ml/models/heads/linear.py` and wire it into a fresh regression fit in `ml/train.py`. Use Xavier uniform with gain `0.01` and set the bias to the mean index of eligible training slides, read from dataset label metadata without decoding bags. Compute this separately inside each fit partition. Apply it only when requested, before training and after verifying the targets are finite. On resume or checkpoint evaluation, restore the saved head. Use zero head dropout for all fixed-recipe arms so projector dropout is the regularizer being varied.
- [ ] Add an opt-in training-only tile cap to `SingleScaleDataset`, drawing 1,024 distinct rows uniformly without replacement on every fetch and retaining every row in shorter bags. Sample before tensor conversion and device transfer. Seed the loader shuffle and tile RNG independently of model initialization. Use the same sampling stream for matched seed and fold across fixed-recipe arms, with fresh draws across epochs. Keep validation, test, and prediction uncapped even with a training cap in the resolved config. Train on four variable-length slide bags per optimizer step with equal weight per slide. Add a separate evaluation batch size of one through `ml/data/datamodule.py`. A Parquet read still decodes a full slide. Measure host I/O and peak device memory in the pilot before optimizing the loader. If full-bag evaluation exceeds memory, use exact chunked projection and pooling with a running sum/count for mean and a numerically stable weighted sum for attention.
- [ ] Add Hydra presets under `configs/experiment/ml/` for the matched linear control, ABMIL-mean, and ABMIL-attention. Share an AdamW recipe with `lr=1.5e-4`, `weight_decay=1e-3`, MSE training loss, and epoch-wise cosine annealing over 50 epochs to `eta_min=1e-6`. Give the three arms the same 50-epoch budget and save the checkpoint with lowest validation MAE, preferring the earlier epoch on a tie. Record the initial prediction mean and SD on a fixed training probe, the training target mean and SD, early validation loss, optimizer steps, LR, and best epoch. Keep the existing linear config and its training recipe available as the historical comparison.

**Acceptance.** Compose all presets and run a CPU fit, save, reload, and validation pass on synthetic variable-length Parquet bags. Check that the output is scalar, the head starts near the training label mean, a restored head retains its bias, and a four-slide batch produces one optimizer update. Test that equal-mean bags can give different outputs after projection, sampling is repeatable with a fixed seed and changes across epochs, and a one-tile or oversized evaluation bag uses all its tiles. If chunking is needed, compare full and chunked scores and attention on the same fixtures.

## 3. Run the paired validation benchmark

- [ ] Prepare `scripts/ml/run_abmil_comparison.py` to expand the frozen matrix, print the resolved commands and target, and track checkpoints and run IDs by fold, seed, and configuration. Run the four neural arms on seeds **0, 1, 2, 3, 4**, with the same split assignments. The core matrix uses 20 fits on a fixed split. Ridge is a deterministic fit per split or fold and is paired with each neural run on the same validation rows.

  | Arm | Tile representation | Pooling | Recipe |
  | --- | --- | --- | --- |
  | Ridge reference | Full-bag raw tile means | Mean | Option 3 or matched ridge |
  | Current linear | Raw 2,560-wide tiles | Mean | Existing regression preset on the pinned L2 card |
  | Matched linear | Raw 2,560-wide tiles | Mean | Fixed AdamW recipe and tile sampling |
  | ABMIL-mean | Projected tiles | Mean | Fixed AdamW recipe and tile sampling |
  | ABMIL-attention | Projected tiles | Gated attention | Fixed AdamW recipe and tile sampling |

- [ ] Run a one-factor sensitivity check for each projected arm on seeds **0 and 1**, against its nominal runs on those seeds. Use width **128**, dropout **0.35**, and LR **2e-4** as the three single-change variants. This adds 12 fits on a fixed split. Report paired deltas as exploratory sensitivity. Keep model selection restricted to the prespecified core arms.
- [ ] Force `test_after_fit=false` for every comparison job because `configs/ml.yaml` enables it by default. Export checkpoint predictions using the explicit validation loader because the existing `mode=predict` path resolves to test. Add a split guard to the runner and a smoke test with a test loader that raises if accessed. Store resolved config, code and environment revision, manifest digest, seed, fold, run ID and checkpoint ID with each result. Pilot on development data and record memory, throughput and projected run cost. Verify the matrix locally before requesting explicit approval for each cluster submission with its jobs, context, namespace, resources and output paths.
- [ ] Create or update `.agents/skills/abmil-regression-comparison/SKILL.md` with the reusable launcher and evaluation commands, managed authentication, target verification, dry-run, expected artifacts, retry and cleanup. Independently review split integrity, checkpoint selection, and the evaluation guard before the full benchmark. Verify and commit the remote workflow scripts and skill together.

**Acceptance.** A local dry-run enumerates the expected matrix and refuses test access. Every approved validation fit yields a best checkpoint and a complete prediction export on the frozen cohort. Retries reuse the same manifest, fold, seed and resolved overrides.

## 4. Score predictions and check attention

- [ ] Implement shared regression scoring in `ml/metrics/regression.py` and export per-slide `slide_id`, target, raw score, fold, seed, and tile count with `scripts/ml/evaluate_abmil_comparison.py`. Compute MAE, MSE, Spearman on continuous targets and scores, and sign-AUROC with `target >= 0` as the positive class and the raw predicted index as the ranking score. Reuse the metric semantics from `origin/feat/concept-explainability:ml/test_evaluation.py`. Calculate rank metrics over the full evaluation cohort, with explicit undefined values and reasons for constant rank inputs or a single target class. If exposed through Hydra during training, use the same definitions for epoch-level validation and test metrics. Test that zero is positive, tied scores are handled, and missing, duplicate or unmatched prediction rows fail the comparison.
- [ ] Report validation metrics for every core arm as **mean ± sample SD across five seeds**, with individual seed scores and paired deltas for all four metrics against ridge and current linear. Also report projected-versus-matched-linear deltas. Ridge gets one pooled validation or out-of-fold score per metric and no seed SD. Use `candidate − reference` throughout. For slide-level MAE, bootstrap the paired predictions using 10,000 seeded resamples of patient groups where grouping is verified, or slides otherwise. Use the same resample across methods and seeds. Report a 95% percentile interval for the seed-averaged paired delta and state that it is conditional on the trained fits. Show cohort size, exclusions, improvement direction by seed, and separate sensitivity results.
- [ ] Evaluate attention on the full validation bags at the nominal checkpoints. Check finite nonnegative weights summing to one. Report the per-slide effective tile fraction `1 / (N * sum(w²))`, top-decile weight mass, and the seedwise distribution. Track the training trend against an initialization snapshot on a fixed development probe. Use bags with at least 20 tiles for the concentration and faithfulness gates and publish their coverage. Apply the same resampling unit and interval method as for MAE to the eligible slides' faithfulness deltas.
- [ ] Adapt the deletion workflow from `origin/feat/explainability:ml/explainability/faithfulness.py` to rank by raw attention weights on projected tiles. For fractions 0%, 5%, 10%, 20%, 30%, 40%, and 50%, remove the same count of top-attention, bottom-attention, or randomly ordered tiles. Renormalize attention over the retained tiles. Use at least 20 seeded random orders per slide and compare the area under the **absolute** change in predicted index from the intact bag. Either sign can be evidence for index regression. Define faithfulness as top-removal area minus mean random-removal area and report the bottom-removal control. Test a uniform/constant control and a high-attention signal fixture. Count tied ranks consistently and verify the fast pooled deletion path against direct reruns if used.

**Acceptance.** The report reproduces from prediction and attention artifacts. The attention report shows whether weights meaningfully depart from uniform and whether deleting attended tiles changes predictions more than random deletion.

## 5. Lock the validation decision and run test once

- [ ] Freeze the proposed go rule before reading validation scores. For an ABMIL arm, require **at least 2% lower mean MAE than ridge**, an upper 95% paired MAE interval below zero against ridge, improvement in at least **4 of 5** seeds against both ridge and matched linear, and lower mean MAE than current linear. Require mean Spearman and sign-AUROC to be within **0.02** of ridge or better. Undefined guardrail metrics leave the promotion criterion unmet. For ABMIL-attention also require the median of the five seedwise median effective tile fractions to be **≤ 0.90** and mean faithfulness to be positive in at least **4 of 5** seeds, with a paired bootstrap lower 95% bound above zero for the seed-averaged faithfulness. These thresholds are proposed experiment criteria to pin with the manifest.
- [ ] Select the lowest mean validation MAE among qualifying arms, preferring mean pooling on an exact tie. If neither qualifies, recommend no-go and select the best linear reference by validation MAE, preferring ridge on an exact tie. Report the deciding comparisons, seed spread, learning curves and attention diagnostics. A no-go on the available evidence can include an inconclusive improvement within seed noise.
- [ ] Lock the chosen config, source and split digest, fixed seed **0** for a neural arm, and checkpoint or ridge model digest before test access. On the fixed split, use the saved validation-selected checkpoint or ridge fit. If using the verified CV protocol, refit seed 0 on the eligible development cohort with the median selected epoch count from its folds and the prespecified schedule, then lock that checkpoint. For ridge in CV, tune alpha using folds within the eligible development cohort, then lock the refit. Run a single held-out prediction pass for the locked model after explicit cluster approval if needed. Publish test MAE, MSE, Spearman, and sign-AUROC once, without seed SD. Keep its prediction artifact for reproducing the report without another inference pass.
- [ ] If the L1 task succeeds, repeat the frozen validation benchmark on its registered artifacts. For a resolution comparison use the shared-slide, matched-bag L2 control defined in the L1 plan. Keep the L2 decision and single test evaluation intact.

**Done.** Both ABMIL presets run end to end. Validation results include five-seed summaries, paired differences and sensitivity checks. The report states whether attention is concentrated and faithful and gives a go/no-go recommendation. One locked setting has a held-out test report.
